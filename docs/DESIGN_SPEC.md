# 🎨 청약 분석 대시보드 디자인 명세서 (Design Specification)

이 문서는 '청약 분석 대시보드'에 적용된 모든 디자인 구성 요소와 원칙을 정의합니다. 본 문서에 정의된 디자인은 시스템의 브랜드 아이덴티티이며, 사용자의 시각적 경험을 일관되게 유지하기 위한 **최종 명세**입니다.

> [!IMPORTANT]
> **디자인 변경 거버넌스(Governance Policy)**
> 본 문서에 기재된 디자인 요소(UI, 폰트, 컬러, 레이아웃 등)를 수정하거나 변경하기 위해서는 **반드시 사용자의 명시적인 사전 승인**을 받아야 합니다. 승인 없는 무단 변경은 엄격히 금지됩니다.

## 🅰️ 타이포그래피 (Typography)

| 구분 | 명세 | 비고 |
| :--- | :--- | :--- |
| **기본 폰트** | `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif` | 시스템 폰트 기반의 가독성 강조 |

## 🎨 컬러 시스템 (Color Palette)

### 🔵 Primary & Status
- **Main Blue (`#0066cc`)**: 주택명 링크, 결과 확인 상태, 클릭 강조 효과, 주요 경쟁률 강조
- **Status Orange (`#ff9800`)**: '접수 마감' 상태 (주의 및 진행 중 의미)
- **Status Grey (`#666666`)**: '청약 예정' 상태 (대기 상태)
- **Status Light Grey (`#999999`)**: '일정 미정' 상태

### ⚪ Background & Border
- **App Background (`#f5f5f5`)**: 대시보드 전체 배경 (Soft Grey)
- **Component Background (`#ffffff`)**: 테이블 및 카드 내부 배경 익
- **Section Border (`#e5e7eb` / `#dddddd`)**: 컴포넌트 간 구분선 (Thin Line)
- **Sticky Background (`#f1f3f5`)**: 테이블 고정 컬럼(합계 등) 배경

## 🏗 레이아웃 및 컴포넌트 (Layout & Components)

### 1. 메인 리스트 테이블
- **Header**: 회색 배경(`f3f4f6`), 볼드 텍스트, 중앙 정렬
- **Row**: 마우스 호버 시 부드러운 하이라이트 효과
- **Cell**: 숫자 데이터 우측 정렬, 하단에 상세 정보 부기(괄호 경쟁률 등)

### 2. 확대형 행 (Expandable Rows)
- **트리거**: 주택명 클릭 시 하단에 아코디언 형태로 펼침
- **스타일**: 20px 패딩, 상단 2px 메인 블루 보더 라인
- **디자인**: 테이블 내부에 중첩된 상세 정보 구성, 가로 스크롤 지원

### 3. 상세 정보 테이블 (Expanded Detail Content)
- **고정 컬럼**: '타입' 컬럼을 좌측에 고정 (Sticky)
- **경쟁률 로직**: 
  - 경쟁률 10 미만: 소수점 2자리 표시
  - 경쟁률 10 이상: 소수점 1자리 표시
  - **해당지역 경쟁률**을 메인Competitive Rate 하단에 소수로 부기하여 청약홈과 대조 가능하도록 함

## 📱 반응형 명세 (Responsive Web)
- **기준점 (Breakpoint)**: `740px`
- **전환**: 740px 미만 시 테이블 구조에서 **카드형 레이아웃**으로 스위칭
- **데이터 레이블**: `data-label` 속성을 이용한 속성명 자동 표시

## 🛠 코드 관리 원칙
1. 디자인 관련 CSS 수정 시 `globals.css` 또는 `page.tsx` 내 인라인 스타일을 직접 수정하지 말고, 위 명세를 먼저 검토한다.
2. 모든 신규 컴포넌트는 위 컬러 팔레트와 타이포그래피 규칙을 상속받아야 한다.
3. 디자인 변경 제안 시에는 **변경 전/후 비교(Before & After)**를 포함한 기획안을 제시하고 승인을 득한다.
