## 1) 개요 및 권장 방식
- 소규모/중간 데이터(수백~수천 행): **클라이언트에서 SheetJS(xlsx)**로 즉시 다운로드 권장.
- 대용량/권한제어/로그 필요: **서버에서 exceljs**로 파일 생성 후 스트리밍 제공.
- 간편 폴백: **CSV** (UTF-8 BOM 포함 — 엑셀에서 한글 깨짐 방지).

## 3) 클라이언트 방식 (SheetJS) — 권장 (빠름)
- 파일: `src/components/ExportExcelButton.tsx`
- 목적: `rows` 배열(정규화된 JSON)을 받아 `.xlsx` 파일 생성 및 다운로드

> **중요**: `rows`는 숫자와 문자열 타입이 명확히 구분되어 있어야 합니다(예: `54850` 숫자, `단위: '만원'` 별도 컬럼).

### 컴포넌트 예시
```tsx
'use client';
import React from 'react';
import * as XLSX from 'xlsx';

type Row = Record<string, string | number | null>;

export default function ExportExcelButton({ rows, filename = '청약_접수결과.xlsx' }: { rows: Row[]; filename?: string }) {
  const handleExport = React.useCallback(() => {
    if (!rows || rows.length === 0) { alert('내보낼 데이터가 없습니다.'); return; }
    const headers = Object.keys(rows[0]);
    const ws = XLSX.utils.json_to_sheet(rows, { header: headers });
    const wb = XLSX.utils.book_new();
    XLSX.utils.book_append_sheet(wb, ws, '청약결과');
    XLSX.writeFile(wb, filename);
  }, [rows, filename]);

  return <button onClick={handleExport}>엑셀 다운로드 (.xlsx)</button>;
}
```

### 주의사항
- 브라우저 메모리 한계: 수천~만 행은 느려지거나 실패할 수 있음.
- 숫자/날짜 타입이 필요하면 `rows`에서 타입을 미리 변환(숫자→number)해야 함.

## 4) 서버 방식 (exceljs) — 대용량/로그/보안
- 파일: `src/app/api/export-excel/route.ts` (App Router)

### 서버 라우트 예시
```ts
// src/app/api/export-excel/route.ts
import ExcelJS from 'exceljs';
import { NextRequest } from 'next/server';
import { fetchAptRowsServer } from '@/lib/detail-data';

export async function GET(_req: NextRequest) {
  const rows = await fetchAptRowsServer();
  const workbook = new ExcelJS.Workbook();
  const sheet = workbook.addWorksheet('청약결과');

  if (!rows || rows.length === 0) {
    sheet.addRow(['데이터 없음']);
  } else {
    const headers = Object.keys(rows[0]);
    sheet.addRow(headers);
    rows.forEach(r => { sheet.addRow(headers.map(h => r[h] ?? null)); });
    sheet.columns.forEach(c => { c.width = 18; });
  }

  const buffer = await workbook.xlsx.writeBuffer();
  const filename = `청약_접수결과_${new Date().toISOString().slice(0,10)}.xlsx`;
  const headers = new Headers({ 'Content-Type': 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet', "Content-Disposition": `attachment; filename*=UTF-8''${encodeURIComponent(filename)}` });
  return new Response(Buffer.from(buffer), { status: 200, headers });
}
```

### 클라이언트에서 호출 (다운로드)
```tsx
'use client';
export default function DownloadFromApiButton() {
  const handleClick = async () => {
    const res = await fetch('/api/export-excel');
    if (!res.ok) { alert('다운로드 실패'); return; }
    const blob = await res.blob();
    const url = URL.createObjectURL(blob);
    const a = document.createElement('a');
    a.href = url; a.download = ''; document.body.appendChild(a); a.click(); a.remove(); URL.revokeObjectURL(url);
  };
  return <button onClick={handleClick}>서버 엑셀 다운로드</button>;
}
```

## 5) CSV 간단 방식 (폴백)
- 간단 구현: 테이블 DOM을 CSV로 변환해 Blob으로 다운로드.
- **한글 깨짐 방지**: CSV 앞에 UTF-8 BOM(`\uFEFF`) 추가.

```ts
function downloadCsv(rows: any[], headers: string[], filename = '청약_접수결과.csv') {
  const bom = '\uFEFF';
  const lines = [headers.join(',')].concat(rows.map(r => headers.map(h => { const v = (r[h] ?? '').toString().replace(/"/g, '""').replace(/\n+/g, ' '); return v.includes(',') ? `"${v}"` : v; }).join(',')));
  const csv = bom + lines.join('\r\n');
  const blob = new Blob([csv], { type: 'text/csv;charset=utf-8;' });
  const url = URL.createObjectURL(blob); const a = document.createElement('a'); a.href = url; a.download = filename; a.click(); URL.revokeObjectURL(url);
}
```

## 6) 데이터 정규화 규칙 (권장)
- 금액: `54,850 만원` → 숫자 `54850` + `통화단위: '만원'` 별도 컬럼
- 건수/수량: `1,103` → 숫자 `1103` (쉼표 제거)
- 비율: `0.38 : 1` → 텍스트
- 다중값(특별공급): `'기관추천:1|신혼:8|생애최초:37'` 형태로 하나의 셀에 넣거나 별도 컬럼 분리

## 8) 노션에 새 페이지로 게시하는 방법
- 두 가지 방법:
  1. **토큰 제공 방식**: 사용자가 Notion Integration Token + 부모 페이지 ID 제공 → 제가 Notion API로 페이지 생성(본문은 이 마크다운을 HTML/블록으로 변환해 업로드).
  2. **붙여넣기 방식**: 통합 토큰 제공을 원치 않으면, Notion에 붙여넣기 가능한 완성 마크다운을 제공(이 파일을 복사해 Notion에 붙여넣으면 자동으로 블록 변환됨).

- 만약 제가 직접 게시하려면 `Integration Token` + `Parent Page ID`를 보내주세요. (보안이 걱정되시면 토큰 제공 대신 붙여넣기용 마크다운을 받으세요.)
